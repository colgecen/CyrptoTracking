# CryptoTrack Kullanıcı Rehberi

## Kurulum
1. .NET 8 SDK kurun.
2. `dotnet run --project AvaloniaAppCrypto` ile çalıştırın.

## Özellikler
- Dashboard: piyasa özeti, BTC grafikleri, coin listesi.
- Favoriler: coinleri yıldızlayın.
- Portföy: giriş ekleyin, P/L görün.
- Alarmlar: fiyat eşiği belirleyin.
- Haberler: güncel kripto haberleri.
- Ayarlar: tema, para birimi, API anahtarları, yenileme aralığı.

## API Anahtarları
Ayarlar ekranından CoinGecko ve CryptoCompare anahtarlarını girin. Anahtarlar yerel ayar dosyasında saklanır.

## Yenileme
- Üst bardaki ↻ butonu veya F5 ile manuel yenileme.
- Ayarlardan otomatik yenileme aralığı seçin.
